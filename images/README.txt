FOLDER GAMBAR — Paramabira @Semarang
=====================================

Taruh semua file PNG/JPG kamu di folder ini.

CARA MEMASUKKAN FOTO PRESTASI (Achievement):
1. Simpan file PNG kamu di folder ini, misal: juara1-nasional.png
2. Buka file index.html, cari bagian ACHIEVEMENTS.
3. Pada kartu yang diinginkan, ganti:
      <img src="" ...>
   menjadi:
      <img src="images/juara1-nasional.png" ...>
4. Ganti juga teks [Tahun], [Judul Prestasi], dan [deskripsi].

CARA MEMASUKKAN FOTO GALERI:
- Sama seperti di atas, cari bagian GALLERY di index.html,
  ganti src="" dengan images/namafile.png

Ukuran gambar yang disarankan:
- Achievement: rasio 4:3 (misal 800x600 px)
- Galeri: rasio 1:1 (persegi, misal 600x600 px)
